# Data Engineering & Data Science Portfolio

Репозиторий содержит учебные и практические проекты по анализу данных, построению ETL-пайплайнов и машинному обучению. Основной упор сделан на работу с большими данными с использованием **PySpark**, разведочный анализ средствами **Pandas** и исследование внутреннего устройства вычислений в Apache Spark.

## 📂 Структура репозитория и описание файлов

### 🎓 Учебные проекты

*   **`01_eda_pandas_hiv_fires.ipynb`**
    *   **Тема:** Разведочный анализ данных (EDA).
    *   **Описание:** Работа с табличными данными (мониторинг ВИЧ и лесные пожары) с помощью Pandas. Оптимизация типов данных для экономии памяти, поиск аномалий (метод IQR), визуализация распределений и корреляционный анализ.
*   **`02_spark_sql_ecommerce_etl.ipynb`**
    *   **Тема:** ETL и Spark SQL.
    *   **Описание:** Построение аналитических витрин на данных e-commerce. Соединение таблиц, агрегации, работа через DataFrame API и Spark SQL, экспорт результатов в формат Parquet.
*   **`03_spark_performance_benchmarks.ipynb`**
    *   **Тема:** Оптимизация и внутреннее устройство Apache Spark.
    *   **Описание:** Исследование физических планов выполнения запросов. Сравнение `repartition` и `coalesce`, бенчмарк `Sort-Merge Join` против `Broadcast Hash Join`, влияние кэширования и проблема мелких файлов.
*   **`04_spark_ml_regression.ipynb`**
    *   **Тема:** Машинное обучение (Spark MLlib).
    *   **Описание:** Построение регрессионной модели. Сравнение Linear Regression и Random Forest, обработка категориальных признаков (StringIndexer, OneHotEncoder), оценка важности признаков.
